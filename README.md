# 🛒 BrightCart — Marketing & Sales Dashboard

**Portfolio Project • Built with Python | Pandas | Plotly | Streamlit**

BrightCart is an interactive marketing analytics dashboard that visualizes revenue, ad spend, and profitability across multiple channels (Email, Google Ads, Meta Ads, Organic Search).  
Deployed on Streamlit Cloud as a live portfolio demo.

---

## 🌟 Features
- 📊 Filterable Streamlit interface  
- 📅 Date-range & channel filters  
- 💵 KPI cards (Total Revenue, Profit, ROAS, Margin)  
- 📈 Weekly Sales vs Spend line chart  
- 💰 Profit & ROAS by Channel  
- ⚙️ Efficiency scatter chart  
- 🔍 Dynamic Insights summary  

---

## 🧠 Tech Stack
- Python 3.10+  
- Pandas • NumPy  
- Plotly Express  
- Streamlit  

---

## ⚙️ Run Locally
```bash
git clone https://github.com/foranyent/BrightCart_Ecommerce_Dashboard.git
cd BrightCart_Ecommerce_Dashboard
pip install -r requirements.txt
streamlit run app.py
```
